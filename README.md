# Plataforma gamer con portal PackZip

Este repositorio contiene la documentación y el prototipo visual para una plataforma web "todo en uno" con autenticación obligatoria, orientada a comunidades gamer y con temática Minecraft/Valorant.

## Demo estática

- Abre `index.html` en tu navegador para explorar la landing futurista con micro-interacciones.
- Los estilos se encuentran en `styles.css` y la capa de animaciones en `script.js`.
